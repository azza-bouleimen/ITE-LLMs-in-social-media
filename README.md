# ITE in Social Media Simulations
This is the code for the paper [Illusory Truth or Mere Exposure? Model-Dependent Repetition Effects in LLM-Based Social Media Simulations](https://arxiv.org/pdf/2609.36278) published at COLM 2026.

* In `experiment.py` there is the script to run the experiment simulating social media feed and ratings of claims.
* In `analysis.ipynb` there is the code to generate the plots of the paper as well as the Linear Regression results.
* In `analysis.R` there is the R script for the Linear Mixed-Effect Model.
* `template_open_weights.job` contains an example of code for running the scripts on a cluster.
